# cmake_util

Shared ZetaX CMake helpers maintained by `zeta_forge`. This directory is the
maintained copy of the legacy standalone project. Projects use their own
`zbuild.py` entrypoints and consume these files as CMake modules.

- [English documentation](../doc/en/cmake_util.org) (primary)
- [简体中文文档](../doc/zh-CN/cmake_util.org)

The guides cover dependency package configuration, legacy compatibility modules
and the `add_run_target` helper.
