* Scope

This is a working-tree implementation record, not a release or an all-platform
acceptance claim. No versions, tags or commits were created. Existing practice
manifest/planning edits and agent's untracked .vorg.db were preserved. No third-party
source, dependency lockfile or existing immutable Rust baseline was changed.
Cat's new 1.97.1-r2 baseline records its existing locked direct dependencies.

All seven buildable repository entrypoints were exercised for help, list,
build/test dry-run, profile selection and rejection of removed flags. Additional
shared tests cover selection, unsupported capabilities, preflight-before-execution,
failure/interruption, argument redaction, CMake components, Cargo/Dioxus features,
profile cleanup including Dioxus server/wasm caches, and Android APK preservation.

Do not use these results to imply that every delivery or platform passed.
The zpp logging failures were observed, not repaired as part of this build-entry
change. Missing native packages must be prepared explicitly; build never installs
host packages to work around a failed validation.
