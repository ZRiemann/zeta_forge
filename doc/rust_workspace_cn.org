#+STARTUP: indent
#+TITLE: Zeta Forge Rust 工程治理

* 目标与归属

=zeta_forge= 统一批准 Rust 工具链、第三方直接 crate 的精确版本与来源，以及应用能力所需的 Cargo 工具。业务仓库拥有源码、workspace 成员、普通 Cargo feature 组合和提交的 =Cargo.lock=。Cargo 解析完整依赖图；Forge 校验直接依赖是否在批准目录内。Conan 只管理 C/C++ package。

* 工具链与依赖目录

=rust/toolchains/<channel>.toml= 固定 Rust channel、profile 和 component。项目的 =rust-toolchain.toml= 必须与选中的 Forge 文件完全一致。=rust/catalog.toml= 的每个依赖条目批准一个 crate 的精确 registry 版本或 HTTPS Git URL 加完整 commit；同一 crate 可以有多个已批准版本。项目可选择其中一个版本，增加普通 feature 不需要新增目录条目。目录中的 =required-features= 与 =default-features= 仅用于明确必需的约束，例如 =rusqlite/bundled= 和原生 NNG binding。

#+begin_src toml
[[dependencies]]
name = "rusqlite"
version = "=0.40.2"
required-features = ["bundled"]

[[dependencies]]
name = "anng"
git = "https://github.com/nanomsg/nng-rs"
rev = "a474ee0272d18f20c360837e2f602dc53ae3b9ec"
default-features = false
required-features = ["tokio"]
#+end_src

项目根目录的 =zeta-rust.toml= 使用 schema 2：

#+begin_src toml
schema = 2
manifest = "frontend/Cargo.toml"
toolchain = "frontend/rust-toolchain.toml"
capabilities = ["dioxus-desktop"]
native-dependencies = ["nng", "openssl-conan"]
#+end_src

Cargo workspace 的 =[workspace.dependencies]= 精确选择 Forge 已批准的版本或来源。成员 crate 必须通过 =workspace = true= 继承第三方依赖；仓库内的 crate 通过 =path= 依赖。提交 =Cargo.lock=，执行命令使用 =--locked=。新增直接依赖时先在 Forge 审批条目，再修改项目 Cargo manifest 和 lockfile；不创建整套依赖快照。

* 应用能力与工具

=dioxus-desktop= 要求 workspace 采用已批准的 Dioxus，并检查匹配版本的 Dioxus CLI。=dioxus-web-fullstack= 另外检查所选 Rust 工具链的 =wasm32-unknown-unknown= target。业务项目自行选择 =dioxus/web=、=dioxus/server=、=dioxus/fullstack= 等应用 feature。

Cargo 工具按工具链、名称、版本隔离在 =${ZETA_INSTALL_PREFIX}/share/zeta_forge/rust-tools/<channel>/<tool>/<version>/bin=，不回退全局 =PATH=。=doctor= 只读检查并在缺失时报告路径。所选 Rust 交付项需要的工具缺失或版本不符时，=check=、=build=、=rebuild=、=test=、=dev= 和 =fetch= 使用固定工具链与 =--locked= 安装 Forge 批准的版本。工具准备在全部预检完成后、构建及 rebuild 清理前执行；安装需要访问 crate registry，失败时不清理项目构建产物。等价的独立安装命令如下：

#+begin_src bash
cargo +1.97.1 install dioxus-cli --version 0.7.10 --locked --force \
  --root "${ZETA_INSTALL_PREFIX:-$HOME/.local}/share/zeta_forge/rust-tools/1.97.1/dioxus-cli/0.7.10"
#+end_src

* 命令与升级

项目通过自己的 =./zbuild.py doctor=、=metadata=、=check=、=build=、=test= 调用 Forge 公共引擎。公共 CLI 默认 release；=--profile debug= 映射 Cargo dev。=doctor= 只读检查工具链、能力工具和原生库；=run= 只使用既有工具与产物；=metadata= 不修改锁文件。构建与检查使用项目已提交的锁文件。

升级工具链时新增相应工具链定义并同步项目 =rust-toolchain.toml=。升级或新增直接 crate 时在目录中批准新精确条目，并由需要它的项目显式采用；未采用的项目不受影响。旧版本条目只有在所有消费者迁出后才可删除。Forge 不读取旧的 =rN= 整套基线格式，也不读取旧的 Cargo 工具安装目录。
