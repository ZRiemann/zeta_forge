* 第三方系统使用 zeta_forge 工具链说明

[[file:readme.org][返回文档首页]] | [[file:../en/third_party_usage.org][English Version]]

本文说明外部项目如何复用 =zeta_forge= 的通用 C++ 编译工具链。架构背景见 [[file:architecture.org][architecture.org]]。

* 前置条件

建议目录布局：

#+begin_src text
$ZETAX_ROOT/
  zsa/
  zeta_forge/
  your_project/
#+end_src

加载 =zsa= 环境后，=ZETAX_ROOT= 会指向顶层工作区。也可以不依赖 =zsa=，直接手动设置 =ZETAX_ROOT=：

#+begin_src bash
export ZETAX_ROOT=/path/to/workspace
export ZETA_INSTALL_PREFIX=$HOME/.local
#+end_src

首次使用前，建议准备 zeta_forge 工具链：

#+begin_src bash
cd "$ZETAX_ROOT/zeta_forge"
./common/prepare_debian.sh
./zbuild.py build
./zbuild.py install grpc
./zbuild.py install hpx
./zbuild.py install folly
./zbuild.py install nng
#+end_src

* 关键环境变量

- =ZETAX_ROOT=：ZetaX 顶层工作区根目录，例如 =~/git=。
- =ZETA_INSTALL_PREFIX=：依赖安装前缀，默认 =~/.local=。
- =ZETA_3RD_DIR=：第三方源码根目录，默认 =$ZETAX_ROOT/zeta_forge/3rd=。
- =ZETA_CMAKE_UTIL_DIR=：公共 CMake helper 目录，默认 =$ZETAX_ROOT/zeta_forge/cmake_util=，通常由 =zeta_forge= Builder 注入给 CMake。
- =ZETA_<NAME>_SRC_DIR=：覆盖某个源码目录，例如 =ZETA_GRPC_SRC_DIR=、=ZETA_TASKFLOW_SRC_DIR=。项目也可以定义自己的源码变量，例如 zpp 使用 =ZETA_ZPP_SRC_DIR=。

外部项目不需要额外引入 forge 专用根变量；公共路径契约统一为 =$ZETAX_ROOT/zeta_forge=。

* 最小项目入口

参照 =zpp/zbuild.py= 的薄入口：定位共享库，导入 =build_cli.cli=，调用本项目
=builder/<project>.py= 中的 =project(script_path)=。不要复制参数解析器或 Forge 内部路由。
项目定义返回 =Project=，声明 =Product=、原生适配器、默认集合及必要的应用步骤。

原生 CMake 项目可保留 =CMakeProjectBuilder= 子类的 configure_command 和依赖校验，
交由 =CMakeEngine= 选择真实 target、测试集合和 install component。
Rust 项目使用 =RustEngine/RustTarget=；Android 使用 =GradleEngine=。
新增内部模块不需要注册 CLI 目标；仅新增正式独立成果时声明目标。
详见 [[file:build.org][公共入口契约]]，不要建立业务 subsystem 注册或重复依赖图。

* 复用依赖配方

外部项目有三种依赖管理方式：

1. 直接依赖 =ZETA_INSTALL_PREFIX= 中已安装的 gRPC、HPX、Folly、NNG 等库。
2. 项目确有私有依赖时，才在项目自己的 =builder/conanfile.py= 中声明；ZetaX 公共 Conan 依赖不得在外部项目重复声明。
3. 如果某个依赖组合会被多个项目共享，优先抽象到 Forge =deps= 交付目标 或其他 forge 公共库能力；项目目标本身仍留在项目仓库。

优先选择第一种或第二种；只有共享价值明确的公共流程才放回 =zeta_forge=。

* zpp 接入范式

=zpp= 是外部项目复用 zeta_forge 的参考结构：

#+begin_src text
$ZETAX_ROOT/zpp/
  zbuild.py
  builder/
    __init__.py
    zpp.py
#+end_src

=zbuild.py= 负责通过 =$ZETAX_ROOT/zeta_forge= 或附近兄弟目录定位 =zeta_forge= 公共库；=builder/zpp.py= 定义 =ZppBuilder=，继承 =CMakeProjectBuilder= 并注入 zpp 特有的 CMake 选项和测试/示例开关。
共享 Conan 依赖版本和 package config 由 =zeta_forge deps= 统一提供，zpp 不维护自己的 Conan 配方。
zpp 的 CMake helper 来自 =$ZETAX_ROOT/zeta_forge/cmake_util=，不再通过 zpp 仓库自己的 =cmake_util= submodule 提供。

* 常见命令

使用 forge 内置目标：

#+begin_src bash
cd "$ZETAX_ROOT/zeta_forge"
./zbuild.py list
./zbuild.py rebuild
./zbuild.py install deps grpc hpx folly nng
#+end_src

在外部项目中使用自己的入口：

#+begin_src bash
cd "$ZETAX_ROOT/your_project"
./zbuild.py build --profile debug
./zbuild.py install
#+end_src

覆盖源码或安装前缀：

#+begin_src bash
export ZETA_INSTALL_PREFIX=$HOME/.local/zeta
export ZETA_TASKFLOW_SRC_DIR=$HOME/git/taskflow
./zbuild.py rebuild
#+end_src

* 故障排查

- 找不到 =zeta_forge=：确认 =ZETAX_ROOT=/path/to/workspace= 已设置，并且 =$ZETAX_ROOT/zeta_forge= 存在；未设置 =ZETAX_ROOT= 时，确认外部项目与 =zeta_forge= 是标准兄弟目录布局。
- 找不到依赖包：确认基础目标已经用 =install= 安装到 =ZETA_INSTALL_PREFIX=，并检查 =CMAKE_PREFIX_PATH=。
- Conan toolchain 不存在：重新运行项目入口并加 =rebuild=，或删除对应 =build/<BUILD_TYPE>/conan= 后重试。
- 源码路径不对：检查 =ZETA_<NAME>_SRC_DIR= 是否覆盖到了预期 checkout。
- 构建目录搬迁后 CMake 报错：使用 =rebuild= 清理当前 build type 的 CMake 状态。

** 兼容性与验证边界

- NNG 的历史 CPM fallback 同步为 =2.0.0=。RC1 到正式版的变化、已有
  zpp API 迁移和后续 Rust FFI 重建要求见 [[file:nng_upgrade.org][NNG 升级与下游适配]]。
- HPX 包含停机、MPI、同步原语和调度器修复，见
  [[file:hpx_upgrade.org][HPX 主线升级与下游适配]]；其中 2026-10-15 的验收结果仅适用于旧提交。
- gRPC 包含代理主机名匹配、取消与泄漏、transport 竞态修复。继续使用
  module provider、代码生成和禁用 archive 下载的配置，不选预发布版。
- Folly 修复 RequestContext、定时器自旋、异步完成处理和协程帧对齐，
  同时删除 =folly::bit_cast=、=folly::invoke=、=folly::prevPowTwo=。
  消费者需检查这些接口，并按需使用对应标准库设施。Folly 不保证提交之间的
  ABI 稳定，下游源码兼容性和性能需要单独验证。
- Builder 保留静态链接、配置的 C++ 标准、Conan 固定版本和功能开关。
  静态检查只核对选项及依赖声明，不代表 CMake 配置或编译通过。Folly 新增的
  缺失依赖下载 fallback 使后续完整构建仍需核对依赖来源；共享依赖继续由 Forge 管理。

本次范围是源码、配置、文档和轻量检查，没有编译安装四个库或重建 zpp/Trader。
已有安装和二进制仍对应旧输入；将来安装后需要重建受影响的静态链接消费者和
Rust FFI。Debug、运行时联调和性能均未验证。

2026-10-22 实际验证记录：

  四个 Builder 选中托管源码，源码预检通过。

** Forge 版本

外部系统依赖 =zeta_forge= 公共行为时，应记录所使用的 =zeta_forge= 版本。当前版本在 [[file:../../VERSION][VERSION]]，发布历史在 [[file:release_history.org][发布历史]]。

当外部项目依赖公共 CLI、环境变量、Conan 配方或 Builder API 时，升级 =zeta_forge= 前应先阅读对应版本的更新说明。
