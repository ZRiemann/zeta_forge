* Zeta Forge

[[file:doc/en/readme.org][English Documentation]] (Primary) | [[file:doc/zh-CN/readme.org][中文文档]]

Zeta Forge is the ZetaX engineering-management layer for source management,
reproducible C++/Rust builds, dependency governance and reusable project tooling.
External projects keep their business code and reuse Forge through their own
thin =zbuild.py= entrypoints.

* Quick Start

Clone with submodules, prepare the host prerequisites, then run commands from
the repository root:

#+begin_src bash
git clone --recurse-submodules <repo-url>
cd zeta_forge
./common/prepare_debian.sh
./zbuild.py list
./zbuild.py build nng --profile release
./zbuild.py install nng --profile release
#+end_src

Host preparation details and all supported workflows are in the
[[file:doc/en/readme.org][English guide]] and [[file:doc/zh-CN/readme.org][中文指南]].
=build= stages outputs locally; =install= publishes explicitly selected,
previously built targets of the same profile. See [[file:BUILD.org][the build contract]].
